# 💰 Smart Expense Tracker & Analyzer

A web-based **Smart Expense Tracker & Analyzer** that helps users record, manage, categorize, and analyze their daily expenses. The application provides visual insights into spending patterns and helps users monitor their monthly budgets.

## 📌 About the Project

Managing daily expenses manually can make it difficult to understand where money is being spent. This project provides a simple and user-friendly platform to track expenses and analyze spending habits.

Users can add their expenses, categorize them, set monthly limits, and view their spending through interactive charts.

## 🎯 Objectives

* Track daily expenses efficiently
* Categorize expenses based on spending type
* Monitor monthly spending limits
* Analyze spending patterns using visualizations
* Provide useful insights into expenses
* Help users make better financial decisions

## ✨ Features

* ➕ Add and manage expenses
* 🗂️ Category-wise expense tracking
* 📅 Daily, weekly, and monthly expense analysis
* 💰 Set monthly spending limits
* ⚠️ Budget limit alerts
* 📊 Interactive charts and graphs
* 📈 Spending pattern analysis
* 🔮 Expense prediction
* 🏆 Reward system for maintaining spending goals
* 👤 User profile management

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/Smart-Expense-Tracker.git
```

### 2. Navigate to the project directory

```bash
cd Smart-Expense-Tracker
```

### 3. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open the application

Open your browser and visit:

```text
http://127.0.0.1:5000/
```
